# fima-macro-releases
Public release/download assets for the FIMA ecosystem.

FIMA Hub releases are free application releases. Their reviewed publication workflow verifies the exact installer SHA256, pinned Ed25519 signature, existing native Windows acceptance evidence, immutable owner identity and exact main commit before publishing a staged draft. This uses owner-dispatched authority; it does not claim a GitHub environment reviewer policy or Authenticode certification.

The Hub workflow does not activate the protected Macro promotion endpoint, paid delivery, Stripe LIVE acceptance or Roblox external-license delivery. Those retain their separate acceptance gates. Hub 1.0.135 native acceptance covers installation/upgrades and the unauthenticated application window; authenticated Macro runtime acceptance is not included.
